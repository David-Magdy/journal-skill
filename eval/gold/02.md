### Conceptual Core
Kozachenko-Leonenko entropy estimation breaks down when mini-batch size $B$ is small ($B \ll D$) because ambient point sparsity dominates over true local density. To maintain the repulsive dispersion force under small per-device batch sizes without cross-iteration autograd graphs, mini-batch vectors compute nearest neighbors against a detached FIFO queue of recent embeddings. Gradients propagate exclusively through the active batch queries.

### Bug / Edge Case Encountered
When querying nearest neighbors across `[batch_embeddings, queue]`, the leading $B \times B$ submatrix represents intra-batch distances. If the diagonal of this leading block is not explicitly masked to infinity, each vector selects itself as its nearest neighbor ($d=0$), producing zero distances and causing logarithmic underflow.

### Key CLI Commands & Environment Tricks
- Asymmetric nearest-neighbor query with leading-block diagonal masking:
  ```python
  dists = torch.cdist(batch_emb, torch.cat([batch_emb, queue.detach()], dim=0))
  dists[:, :batch_size].fill_diagonal_(float('inf'))
  min_dists = dists.min(dim=1).values
  ```
