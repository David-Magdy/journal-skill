# KoLeo Regularization and Contrastive Representation Collapse

## Conceptual Core
In self-supervised Vision Transformers (e.g. DINOv2), teacher-student alignment can collapse representations into a narrow sub-cone of the embedding space. KoLeo (Kozachenko-Leonenko) regularization acts as a repulsive dispersion force by estimating differential entropy via 1-nearest neighbors on the $\ell_2$-normalized unit hypersphere:
$$L_{koleo} = -\frac{1}{n} \sum_{i=1}^n \ln\left(\min_{j \neq i} \|z_i - z_j\|_2\right)$$
Maximizing this entropy forces embeddings to distribute uniformly across the sphere without requiring negative pairs.

## Bug / Edge Case Encountered
When computing pairwise Euclidean distances from cosine dot products using $\|x - y\|_2 = \sqrt{2 - 2(x^\top y)}$, floating-point inaccuracies can yield values slightly greater than 1 for identical vectors, producing negative radicands inside the square root. Clamping the difference with `torch.clamp(2.0 - 2.0 * dots, min=1e-8)` before `torch.sqrt` prevents `NaN` gradients.

## Key CLI Commands & Environment Tricks
- Track representation collapse via off-diagonal pairwise cosine similarity:
  ```python
  sim = torch.mm(p, p.t()).fill_diagonal_(0).mean().item()
  ```
- Efficient pairwise distance computation for normalized vectors:
  ```python
  dists = torch.sqrt(torch.clamp(2.0 - 2.0 * torch.mm(p, p.t()), min=1e-8))
  ```
