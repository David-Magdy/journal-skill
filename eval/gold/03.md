### Conceptual Core
Computing KoLeo regularization under automatic mixed precision (AMP FP16) introduces gradient singularities. As pairwise distance between embeddings approaches zero, the derivative of Euclidean distance $\frac{d}{dx} \sqrt{x} = \frac{1}{2\sqrt{x}}$ explodes to infinity, overflowing FP16 dynamic ranges into `Inf`/`NaN`. Distance matrices and logarithmic estimators must be evaluated in FP32 with an $\epsilon$-stabilized radicand.

### Bug / Edge Case Encountered
When multi-crop augmentation places multiple views of the same image into a single mini-batch, identical or near-identical embeddings have near-zero distance. If masking only zeroes the self-diagonal and ignores multi-crop pairs from the same parent image, the nearest neighbor distance underflows, causing $\ln(0) = -\infty$ and poisoning autograd tensors.

### Key CLI Commands & Environment Tricks
- Force FP32 execution for distance matrix and logarithm:
  ```python
  with torch.cuda.amp.autocast(enabled=False):
      dists = torch.sqrt(torch.clamp(2.0 - 2.0 * torch.mm(p.float(), p.float().t()), min=0.0) + 1e-12)
  ```
- Pinpoint numerical divergence during backward passes:
  ```python
  torch.autograd.set_detect_anomaly(True)
  ```
